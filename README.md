# 의사랑 업데이트 노트 작성 도구

레드마인 티켓을 GitBook 업데이트 노트로 자동 변환하는 내부 도구입니다.

## 주요 기능

- **레드마인 연동**: API를 통해 버전별 티켓 자동 수집
- **직접 붙여넣기**: 레드마인 티켓 목록을 텍스트로 붙여넣어 분석
- **자동 필터링**: `개별대응`, `내부재현불가` 등 제외 규칙 자동 적용
- **티켓 검토**: 포함/제외 수동 조정, 세부 내용(Description) 확인
- **병합 제안**: 같은 모듈의 유사 티켓 자동 감지 및 병합 (수동 병합도 가능)
- **GitBook 초안 생성**: CLAUDE.md 가이드 기반 GitBook 형식 마크다운 출력
- **Claude 프롬프트 생성**: Claude에게 붙여넣을 프롬프트 자동 생성

## 시작하기

### 1. Node.js 설치 (최초 1회)

https://nodejs.org 에서 **LTS** 버전을 다운로드해 설치하세요.

### 2. 실행

`start.bat` 파일을 더블클릭하면 자동으로 설치 및 실행돼요.

브라우저에서 `http://localhost:5173` 접속

> 최초 실행 시 패키지 설치로 1~2분 걸릴 수 있어요. 이후 실행부터는 바로 열려요.

### 개발자용

```bash
npm install
npm run dev
```

## 레드마인 연동 설정

앱 실행 후 **규칙 관리 탭 > 레드마인 연동**에서 API 키와 프로젝트 ID를 입력하세요.

또는 `.env.local` 파일을 생성해 미리 설정할 수 있어요.

```
VITE_REDMINE_API_KEY=your_api_key
VITE_REDMINE_PROJECT_ID=your_project_id
```

## 업데이트 받기

새 버전이 나왔을 때는 아래 순서로 업데이트하세요.

1. 터미널(cmd)에서 프로젝트 폴더로 이동
2. `git pull` 실행
3. `start.bat` 다시 실행

> Git이 없다면 GitHub에서 ZIP으로 다시 다운로드해 덮어씌우면 돼요.

## 자동 병합 규칙

티켓 분석 시 아래 두 조건을 **모두** 충족하면 자동으로 병합 그룹을 생성해요.

1. **같은 모듈** — `[진료실]`, `[보험청구]` 등 모듈명이 정확히 일치
2. **공통 키워드 2개 이상** — 티켓 설명에서 의미 있는 단어를 추출했을 때 겹치는 단어가 2개 이상

키워드 추출 시 조사(이, 가, 을, 를 …)와 일반 단어(기능, 화면, 항목, 버튼 …), 2글자 미만 단어는 무시해요.

> 자동 병합이 부정확한 경우 병합 단계에서 수동으로 조정할 수 있어요.
> 체크박스로 개별 티켓을 선택한 뒤 "그룹으로 묶기" 버튼을 눌러 수동 병합할 수 있어요.
